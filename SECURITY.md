# AXON OS Security Policy

AXON OS takes security, privacy, and controlled execution seriously.

As the project evolves, security mechanisms and runtime protections will continue to improve.

---

# Supported Versions

AXON OS is currently under active development.

Security updates and fixes are applied to the latest active development version.

---

# Reporting Security Issues

If you discover a security issue, vulnerability, or unsafe behavior related to AXON OS:

- Do NOT publish the issue publicly.
- Do NOT disclose exploit details publicly.
- Report issues responsibly.

At this stage of development, security reports should remain private until verified.

---

# Security Principles

AXON OS is being designed around the following principles:

- Local-first execution
- Minimal cloud dependency
- Controlled AI execution
- Modular runtime architecture
- Privacy-focused workflows
- Offline-capable AI systems

---

# Important Notice

Some internal runtime systems and orchestration components are intentionally not included in the public repository for security and development reasons.
