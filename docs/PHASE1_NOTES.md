# Axon OS — Phase 1 Technical Notes
# Boot Interface

---

## What Was Built

Phase 1 delivers two outputs:

### 1. Plymouth Theme (Real Boot Screen)
Files: `plymouth/axon.plymouth` + `plymouth/axon.script`

This installs on Ubuntu and runs at real boot time, before the desktop loads.
It uses Plymouth — Ubuntu's built-in boot splash system.

Features:
- Deep space background (#050812)
- Axon OS logo (PNG, generated from code)
- Pulsing logo animation
- Cyan progress bar linked to actual boot progress
- OS name and tagline text
- Fade-in / fade-out transitions

### 2. Python Simulator (No Installation Needed)
Files: `splash_simulator/main.py` + `config.py` + `animation.py` + `logo_generator.py`

A pixel-accurate preview of the boot screen using pygame.
Run it on any machine to see the experience without touching system files.

```
│   └── logo_generator.py      ← Procedural logo renderer
│
└── scripts/
    ├── install_theme.sh       ← Installs Plymouth theme (needs root)
    └── check_deps.sh          ← Verifies system dependencies
```

---

## Architecture Decisions

| Decision | Rationale |
|---|---|
| Split config into `config.py` | Allows adjusting all visuals without touching logic |
| Procedural logo in code | No external assets needed; logo is always consistent |
| Separate animation.py | Each animated element is an independent class |
| Two-track (Plymouth + simulator) | Plymouth requires root+reboot; simulator enables fast iteration |

## How to Check if Phase 1 is Already Installed

```bash
# Check if theme exists
ls /usr/share/plymouth/themes/ | grep axon

# Check current active theme
update-alternatives --display default.plymouth | grep "link currently"

# Or using plymouth directly
plymouth-set-default-theme --list | grep axon
```

If any of these return `axon`, Phase 1 Plymouth theme is already installed.
You can still run the simulator independently at any time.

---

## Known Limitations

1. Plymouth Script does not support true procedural drawing — the logo must be a PNG.
2. The simulator requires pygame (not available on headless servers).
3. initramfs rebuild takes ~30 seconds on most systems.
